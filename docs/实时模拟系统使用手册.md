# 实时模拟系统使用手册

## 概述

实时模拟系统是基于历史回测验证的量化交易策略的生产级实现，支持cronjob调度、中断恢复、多实例管理等特性。

## 快速开始

### 1. 系统部署

```bash
# 部署系统
python deploy_realtime_simulation.py

# 运行测试
python test_realtime_simulation.py
```

### 2. 基本使用

```bash
# 交互模式
python simulation/main.py --mode interactive

# Cronjob模式（生产环境）
python simulation/main.py --mode cronjob --instance default

# 守护进程模式
python simulation/main.py --mode daemon --instance default
```

## 系统架构

### 核心组件

1. **实例管理器** (`instance_manager.py`)
   - 多实例支持
   - 配置管理
   - 实例隔离

2. **状态管理器** (`state_manager.py`)
   - 组合状态持久化
   - 完整性验证
   - 历史状态追踪

3. **缓存管理器** (`cache_manager.py`)
   - 数据缓存
   - 过期管理
   - 性能优化

4. **任务执行管理器** (`task_execution_manager.py`)
   - 中断恢复
   - 检查点机制
   - 步骤跟踪

### 执行引擎

1. **策略引擎** (`strategy_engine.py`)
   - 选股逻辑
   - 信号生成
   - 策略参数

2. **交易引擎** (`trading_engine.py`)
   - 订单生成
   - 成本计算
   - 执行逻辑

3. **风控引擎** (`risk_engine.py`)
   - 止损止盈
   - 仓位控制
   - 风险监控

## 中断恢复机制

### 检查点系统

系统采用细粒度检查点机制，确保任何步骤的中断都能恢复：

1. **任务级检查点**：记录任务整体进度
2. **步骤级检查点**：记录每个步骤的执行状态
3. **数据级检查点**：记录中间数据和状态

### 恢复流程

1. 系统启动时自动检测未完成任务
2. 加载最新检查点数据
3. 从中断点继续执行
4. 验证数据完整性

### 手动恢复

```bash
# 强制重启（忽略检查点）
python simulation/main.py --mode cronjob --force-restart

# 从特定日期恢复
python simulation/main.py --mode cronjob --resume-from 2025-09-23
```

## Cronjob设置

### 推荐调度

```bash
# 每日数据更新（9:00）
0 9 * * 1-5 /path/to/stock/scripts/data_update.sh

# 每日调仓检查（9:30）
30 9 * * 1-5 /path/to/stock/scripts/daily_rebalance.sh

# 风控监控（每小时，交易时间）
0 9-15 * * 1-5 /path/to/stock/scripts/risk_monitoring.sh
```

### 脚本配置

在`scripts/`目录下提供了示例脚本：

- `daily_rebalance.sh`：日度调仓脚本
- `risk_monitoring.sh`：风控监控脚本
- `data_update.sh`：数据更新脚本

## 多实例管理

### 创建实例

```python
from simulation.core.instance_manager import InstanceManager

manager = InstanceManager()
manager.create_instance("conservative")  # 保守策略实例
manager.create_instance("aggressive")    # 激进策略实例
```

### 实例配置

每个实例有独立的：

- 配置参数
- 状态数据
- 交易记录
- 缓存数据

### 实例操作

```bash
# 列出所有实例
python simulation/main.py --list-instances

# 运行特定实例
python simulation/main.py --instance conservative --mode cronjob

# 删除实例
python simulation/main.py --delete-instance test_instance
```

### 配置参数

#### 策略参数

- `lookback_months`：回看月数（默认6）
- `decline_threshold`：下跌阈值（默认0.20）
- `max_stocks`：最大股票数（默认35）
- `min_listing_years`：最小上市年限（默认5）

#### 风控参数

- `stop_loss`：止损比例（默认-0.15）
- `take_profit`：止盈比例（默认0.20）
- `max_position_ratio`：最大仓位比例（默认0.05）

#### 交易参数

- `commission_rate`：佣金费率（默认0.0001）
- `stamp_tax_rate`：印花税率（默认0.001）
- `slippage_bps`：滑点（默认8bp）
