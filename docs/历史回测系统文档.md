# 量化交易历史回测系统文档

## 项目概述

本项目是一个基于A股市场的量化交易历史回测系统，采用跌幅逆向选股策略，经过5.2年实际数据验证，已优化至生产级别参数。

### 核心特性

- **策略类型**：跌幅逆向选股 + 完整风控模块
- **回测周期**：2020年7月至2025年8月（5.2年）
- **数据覆盖**：707只A股，938,795条真实交易记录
- **交易成本**：万1佣金 + 3bp滑点 + 千1印花税（接近实盘）
- **风控机制**：个股止损/止盈 + 动态风控参数

## 核心文件说明

### 主要系统文件

- **`main_quantitative_system.py`** (594行)
  - 生产友好的量化回测系统主程序
  - 增强ST过滤模块，适合实盘交易
  - 万1佣金 + 3bp滑点 + 完整风控

- **`complete_backtest_system.py`** (656行)
  - 5年期完整回测系统
  - 支持多种基准指数对比
  - 详细绩效分析和年度报告

### 核心算法模块 (`python/stock/`)

- **`data/akshare_provider.py`** - 数据提供者，基于akshare
- **`engine/backtest.py`** - 回测引擎，T+1执行机制
- **`engine/metrics.py`** - 绩效指标计算
- **`engine/risk_control.py`** - 风控模块
- **`strategies/drawdown_reversal.py`** - 跌幅逆向选股策略

## 策略详细说明

### 选股策略

- **逆向选股**：选择6个月跌幅≥20%的股票
- **基础过滤**：上市≥5年，剔除ST股票
- **流动性过滤**：日均成交额≥5000万
- **目标持仓**：35只股票（最优风险分散）

### 调仓机制

- **调仓频率**：每3周调仓一次
- **执行时点**：T+1日开盘价执行
- **仓位管理**：等权重分配，动态再平衡

### 风控机制

- **个股止损**：单股亏损达到-15%自动止损
- **个股止盈**：单股收益达到+20%自动止盈
- **资金管理**：风控触发后资金闲置至下次调仓

### ST过滤系统（生产级）

```python
# 三层验证机制
Layer 1: 股票代码模式识别（ST/SST/*ST前缀检测）
Layer 2: akshare实时API查询验证  
Layer 3: 保守备用策略（网络故障时过滤所有疑似标的）
```
